# VGC Analysis Suite

Pokémon Champions does not give players adequate data to look at about their battles.
This project is an ad hoc solution: it turns recordings of your games into a data set you
can work with.

**Work in progress.** It will eventually be rolled out as a deployed service, in a beta for
the VGC community.

How to run it, and the design notes, are in [`devlog/`](devlog/), starting with
[devlog/Guide.md](devlog/Guide.md).
